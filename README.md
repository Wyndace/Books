# WynWebKit (Books)

Стартер-шаблон для веб-разработки на Nuxt 3 + Tailwind CSS. Обновлённая версия [Books-old-](https://github.com/Wyndace/Books-old-) (Laravel + Nuxt 2).

## Стек

- Nuxt 3
- Tailwind CSS
- TypeScript
- ESLint + Prettier

## Запуск

```bash
yarn install
yarn dev
```

## Статус

В разработке — шаблон периодически обновляется под новые проекты.
